先看这里｜使用者须知

执行提醒：把本仓库交给 Codex、DeepSeek Harness 等 Agent（Claude / Claude Code 除外），直接让它严格按照本包脚本及配套部署步骤执行，不自行更换方案、跳过步骤或增加无关任务。

这份教程可以帮你在自己的电脑里另开一套 Windows，用来安装你选的软件。你先看这份说明，再看同一层的《02_采购清单与工具入口.txt》，了解要准备什么，然后把整个文件夹交给 Codex。安装命令和排查步骤写在《给 Codex 的操作说明》里。

第一步，把教程交给 Codex

1. 下载 ZIP 压缩包，解压整个包。Windows 用户可以放在 D 盘的 Codex 文件夹里。Mac 用户放在自己好找的位置即可。
2. 找到同时能看到《给Codex的操作说明.md》、docs 和 skills 的那一层。用 Codex 打开这个文件夹。
3. 复制下面这句话发给 Codex。告诉它你用的是 Windows 还是 Mac、想用 Claude 网页还是桌面软件，以及有没有已经在用的虚拟电脑或网络。

我第一次用这份教程。请严格按本包脚本及配套步骤部署，不自行更换方案、跳过步骤或增加无关任务。请先读《给Codex的操作说明.md》，检查我的电脑和已有软件。用大白话告诉我能直接做什么、还缺什么、有没有费用，再按我选的方案继续。我用 Mac 时，缺安装文件请先按 Mac 流程第 2 节检查来源、实测下载速度，再开始完整下载。

如果 Codex 说读不到文件，把你实际解压到的文件夹位置告诉它。

第二步，看你的电脑和网络是哪种情况

- Windows 电脑。 先检查版本、虚拟化、资源和权限。按本包现有 Hyper-V 脚本部署时，升级专业版是当前最优解，建议优先升级。家庭版也能使用第三方虚拟机，但本包这条路线尚需适配和实测；由本人决定，Agent 不自动切换。实体电脑与虚拟电脑的 Windows 授权分别核对。
- Mac 电脑。 在苹果菜单里点“关于本机”。看到 M1、M2 等苹果 M 系列芯片，就选 Windows 11 ARM64 安装文件；看到 Intel，就选 x64。ARM64 和 x64 是两种不同的芯片类型，让 Codex 确认后再下载。已有能用的虚拟电脑或验过的原版安装文件，可以直接复用。
- Mac 下载安装文件。 请让 Codex 先查能复用的原版和你有资格使用的国内正版渠道。有缺项就先试下实际文件，告诉你来源、速度和大概要多久。太慢就先暂停。用验过的本地 Windows 安装文件建机。Fusion 或 Parallels 的“获取 Windows”仅在合规的手动渠道都拿不到文件、且你明确同意时才使用。
- 已经有自建 VPS。 VPS 就是租来的远程服务器。把供应商官网、公开教程和你要保留的用途告诉 Codex。有卡顿时可以直接说“请保留我现在的公网 IP，先查慢在哪里”。公网 IP 是网站看到的上网地址。Codex 会分别测电脑到服务器、服务器到网站，再告诉你证据指向哪一段。
- 还没有 VPS。 先让 Codex 检查现有条件。VPS、现成的网络服务和单独购买的上网地址是不同的东西，需要哪项再买哪项。使用 Claude 的资格以服务商的官方支持条件为准。

第三步，这些事由你本人完成

- 登录账号、输入密码和验证码、付款，都在对应的软件或官网页面自己完成。服务器密码、带密码的连接地址、订阅链接和 Windows 产品密钥也留在本机。
- 需要购买 Windows 授权时，先核对要激活的是实体电脑还是虚拟电脑，再确认版本和授权来源。教程不提供激活码。其他工具和原作者分享过的购买入口见同一层的《02_采购清单与工具入口》。
- 如果 Codex 需要重启实体电脑或改正在用的网络，先请它说明会影响什么。遇到 Codex 无法点击的界面，让它写清楚你要打开哪里、点什么、看到什么算成功。

第四步，怎么知道做好了

1. 虚拟电脑能进 Windows 桌面。Windows“国家或地区”和区域格式以最终出口节点地区为准，时区以节点所在城市对应的时区为准；显示语言、准确校时和联网情况分别核对。
2. 如果选了 AdsPower 专用浏览器，请 Codex 在同一个专用窗口里先做网络检测，确认正常后再开 Claude。检测页会看到网络出口，里面无需输入 Claude 密码或验证码。重开窗口、恢复网络或重启后，重新检测。
3. 如果选了网页和桌面软件，请分别试登录和对话。最后让 Codex 写清楚已经做好什么、实际测过什么、还有哪一步要你处理。Mac 上的完整流程和 Windows ARM 里的 AdsPower 仍需现场试用确认。

配置后，其他软件提示无网络怎么办

如果在配置过出站限制的虚拟电脑里使用其他软件时，出现“无网络连接”或无法联网，可能与当前网络规则、代理或 DNS 配置有关。可以把软件名称和具体报错告诉部署人员或 Agent，检查后为该软件单独补充必要的联网放行规则。不要直接关闭防火墙或把所有软件全部放行。

如果只是 Windows 的网络图标显示“无 Internet”，先实际测试软件能否联网，不要仅凭图标判断。新增规则后，还要确认 Claude 的原有网络和断线保护仍然有效。

已经用旧版装过的人，可以把《已部署用户_补齐配置任务.txt》交给原来的 Codex，让它从缺的步骤接着做。
