## 已接通的代码

| 范围 | 当前实现 |
|---|---|
| 平台选择 | 结合系统版本、架构、虚拟化条件、资源与已有安装排序；Windows 三条路线分别实现；保留 Mac 教程但不宣称 Windows EXE 能部署 Mac |
| VirtualBox | 自动获取已固定哈希的官方安装器、无人值守 Windows 与 Guest Additions、Guest Control 传送；初始网卡关闭，联网只走受控 UDP 网关并核对其他网卡、共享和设备状态 |
| Hyper-V | 可选功能准备、二代 VM / TPM / 安全启动、离线应用 Windows、PowerShell Direct；没有普通网卡，独立的管理与持续检查通路避免长安装堵住续期 |
| Workstation | 官方完整安装器识别与发布者签名核验、创建 VMDK / VMX、Windows 应答介质、Tools / VIX；下载登录与首次加密 / TPM 交给本人，后续自动继续 |
| 总线网络 | Hyper-V Socket 与 VMware VMCI / vSockets 分别适配；来宾使用官方未修改的 Wintun L3 适配器进入同一个外部网关，不创建额外 Linux VM |
| 通道认证 | 双向 HMAC、随机挑战，绑定 VM、任务、平台、服务 / 端口、MAC；只传固定长度的 IPv4 包，不传命令或文件共享请求 |
| 来宾原方案 | 保留 Clash Verge Rev 服务、专用配置、TUN、默认拒绝、防火墙精确规则、地区 / 时区、出口与断线恢复检测；只传所选节点 |
| AdsPower | 安装后尝试本机 API，按任务唯一标记新建 / 复用自己的专用环境，配置 SOCKS5、WebRTC 和时区；登录、API 权限不足或验证码给出具体手动指示，不删除现有环境 |
| 应用打开 VM | 核对归属、当前网关及适配器；窗口还需匹配本任务和实际进程、电源状态，不能只看启动命令退出；保存状态不丢弃，暂停状态正常恢复 |
| 恢复与报告 | 使用本次随机操作标识、VM 与任务绑定安装 / 回退结果，拒绝过期或其他环境报告；保留原任务和数据，回退不恢复 NAT / 直连兜底 |
| 界面 | 修复下拉框、动态安装范围、复用缓存进度、刷新误撤销网关；部署中锁定输入；保留左侧功能栏、开发者署名、交流群和自定义配色 |

部署不再无条件抛出“隔离边界尚未达到部署条件”。当前必须通过所选平台的真实配置回读才能启动或续期，失败维持关闭。来宾报告中的通过标记不能授权外层网关。

## 许可提示与镜像身份

旧版最后一步是一句随平台变化的模板，并未读取系统镜像；更新范围文案时还覆盖了 TextBlock，导致长句被截断。

现分别处理组件许可、Windows 使用授权和实际安装范围。先只读挂载 ISO，查询其 WIM / ESD 的名称、版本、架构、客户端类型和索引；只提供识别出的 Windows 11 x64 客户端版本，不要求客户手填索引。Windows 10、Server、ARM64、Linux、没有支持的安装映像或信息不完整时停止。已有挂载不擅自卸载；仅卸载本次创建的挂载。

选中版本后，许可提醒和最终安装范围显示实际名称。更换镜像或版本会取消原有确认；镜像未识别时不能确认 Windows 使用授权。部署前再次检查文件哈希与所选索引。**读取镜像身份和本地哈希不等于认证微软原版、许可证有效或系统激活。** 条款及使用授权仍由本人通过微软官方条款和所选介质核对。

ISO 获取仍使用微软官方媒体创建工具，需要本人在微软窗口确认许可和保存 ISO，不能把 20.6 MB 的下载工具叫作完整系统镜像。没有复制 Cage 的目录下载代码，也没有把 ESD 改后缀当作 ISO。

## 关键隔离修正

- 外部网关只连接固定公网 IPv4 节点和 TCP 端口，拒绝当前主机网段与本地、私网、保留地址及 IPv6；没有公共 UDP、任意 DNS 或 NAT 兜底。15 秒租约、5 秒续期，过期、读取失败、改变配置或应用退出会撤销连接。
- VirtualBox 的 UDP 监听不能仅凭 `dest=127.0.0.1` 判断安全，按 VM 端口和进程建立局部入站保护并回读；该真实效果仍待验收。
- Hyper-V 关闭 KVP 数据交换；初始化清除已知宿主字段。基本会话保护涉及主机全局增强会话策略，单独说明并取得确认，保留原值、按任务记录归属、加互斥，最后一个受保护环境正常关机并撤回时再恢复。
- Workstation 初始与恢复阶段没有普通网卡，关闭 HGFS、剪贴板、拖放、getHostInfo 和设备直通；离线安装同样检查共享设置。加密 / TPM 不只信任确认勾选，回读 VMX 实际设置。
- Hyper-V 安装和持续检查分用管理通路；需要界面的配置经已登录的来宾交互桌面执行，未登录时给出操作指示，不启用 RDP 或网络 WinRM。
- 主机只按清单向自己的来宾发送资源与必要字段，固定读取小报告；没有常驻主机目录共享。来宾管理员能读取交给来宾的节点和账号资料，不能将其宣传为对来宾保密。

这些措施不保证隐藏虚拟化、所有 CPU / 设备特征、云账号关联，也不保证不存在虚拟机逃逸或供应链漏洞。
