# 自动桌面、安装网络与任务保存（unified4）

## 本轮问题与行为

- 控制台实际存在但旧动态 WMI 读取未取到 PID/命令行，异常又被当作窗口不存在。改为有超时的 System.Management 读取，以组件路径和结构化任务身份定位 HWND；进入桌面自动接入，每次明确继续最多请求一次前端。窗口或虚拟机被本人关闭后暂停自动连接，继续任务才恢复，避免反复拉起。
- VirtualBox 安装阶段原来只有节点地址放行，来宾 Clash 尚未安装，Windows 首次设置因而无 Internet。新增官方 Mihomo 校验下载和认证回环 SOCKS 辅助进程，公网 TCP 80/443 与加密 DNS 只经所选节点；拒绝私网、主机地址、其他端口和任意 UDP，不使用 NAT 或直连兜底。配置经标准输入传送，不落盘或写入参数。来宾工具就绪时撤销临时通道并关闭相应流，再验证来宾 Clash。
- 回环辅助进程纳入 kill-on-close JobObject；助手正常退出或被强制结束时一并结束。保留既有租约及失败断开规则，不修改系统代理、主机 TUN、DNS 监听或全局防火墙策略。
- 每 15 秒及暂停/退出时保存部署任务，采用写入并刷新、原子替换、上一份有效记录的方式；损坏主记录可恢复备份。自动保存部署进度不等于保存虚拟电脑中未保存的文档。任务运行中关闭助手提供“继续任务”和“保存并暂停后退出”，等待取消检查点完成后退出。
- 左侧导航、当前任务、逐步指引保持同栏。Windows 语言、地区、键盘、联网、账号、隐私、更新、来宾工具分别提供说明；本人按实际页面选择指引，程序按 Windows / 软件阶段切换，未实现逐屏图像自动识别。
- AdsPower 检查按原环境核对 Windows 图标、查询渠道 ip-api、空启动标签、WebRTC 禁用、实际出口对应的语言/时区与权限；保留其余指纹设置。新建专用环境限定 Windows UA，恢复原环境不重新生成 UA。程序采用 SOCKS5 127.0.0.1:17897；No Proxy 仅适用于已验证整机 TUN 的对应任务，不能照示例覆盖实际配置。检测国家匹配不足以证明没有 DNS/IPv6/WebRTC 泄露，仍保留完整检测和本人登录。

## 已验证的范围

最终自包含 EXE 的标准验证 300 项通过、0 失败：C# 176、离屏 WPF 34、PowerShell 89、已安装 VirtualBox CLI 参数核对 1。Go 网关测试通过，覆盖认证代理、禁止直连、安装网络退出与控制消息校验。离屏图检查左侧指引和维护折叠区域，预览模式禁止真实控制台连接及任务保存。

独立本机合成验证已通过：实际辅助程序启动及认证、正常释放、强制结束父进程后 JobObject 清理；使用虚构 UUID 的隔离原生窗口进程验证实际 WMI 和 HWND 匹配。未以这些结果替代真实客户机联网、鼠标键盘、DPI 或浏览器验收。

证据位于工作区 `output/自动桌面与安装网络交付_2026-11-17/verification-summary.json`、`preview/`，及 `output/外层提交异常定位_2026-11-17/native-bootstrap-test-result.json`。客户 ZIP 另执行 CRC、文件白名单、解压哈希和解压 EXE 的自测/离屏预览。

本人已在开发任务确认 addressfix1 不再出现地址范围错误，脱敏管理员结果 exit=0 / done / 0x00000000；只读回读的两个任务规则、三类防火墙开关与地址覆盖均通过。该项是实机组件证据，不代表新版完整流程验收。
