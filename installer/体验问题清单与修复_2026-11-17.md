# 体验问题清单与修复

目标版本：`0.4.0-dev.20261117.unified1`。本轮是源码维护、打包和离线验证，不操作当前运行的真实虚拟机，不导入真实订阅凭据，不改宿主网络、安全功能或运行中的任务数据。

| 问题 | 已确认的原因 | 本轮实现（代码） |
| --- | --- | --- |
| 一条节点导致整份订阅导入失败 | URI 和 YAML 路径都硬性拒绝跳过节点证书校验；循环没有逐节点容错 | 所有订阅统一处理；保留节点原选项；单条错误独立报告，不影响其他节点 |
| 删除提示后节点仍可能连接失败 | URI 的 allowInsecure 没映射到核心配置 | 正确传递证书选项、SNI 和别名；不关闭订阅 HTTPS 下载本身的验证 |
| 客户 Windows 10 被阻断 | 宿主检测写死 Build >= 22000，提示也固定显示 Windows 11 | 接受约定范围的 Windows 10 x64；按宿主实际系统显示名称，按版本推荐可用后端 |
| 开始/继续部署总退回第 1 步 | 整体入口重跑并重置阶段，检查与安装混在一起 | 按已完成里程碑恢复；已有 VM 复用；已启动安装不再要求重装；已配置应用按实际回读继续 |
| 虚拟机已打开仍尝试打开 | 恢复路径依赖打开外部窗口成功 | 运行恢复与显示窗口分离；继续部署不依赖外部窗口确认 |
| 慢启动被误判失败 | 启动后只立即查询一次运行状态 | 有界轮询 starting/resuming 等中间状态，超时才生成可执行指引 |
| 窗口存在却报未打开 | 仅依赖 COM CanShowConsoleWindow，分离式前端不可靠 | 按 VM UUID 和进程归属查找真实窗口；已有窗口优先复用，避免重复启动或抢焦点 |
| 黑屏、CPU 忙但无安装进展 | 客机输出已确认全黑；宿主 Hyper-V/VBS 生效，VBox 日志为 NEM；具体根因仍待对照 | 程序内提供状态和黑屏诊断；关机后可单独调整兼容配置并回读；不自动关闭宿主安全功能，不宣称已解决实机黑屏 |
| 虚拟机没有封装到程序内 | 当前只有外部 VirtualBox 窗口启动器 | 左侧安装指引，右侧嵌入真实控制台窗口；连接、恢复、断开均复用原 VM，不以静态图片冒充桌面 |
| 共享、设备直通和远程显示报通用错误 | 实际任务共享剪贴板为 hosttoguest，其他项正常；旧提示不指出具体项 | 按项报告当前值与所需值；只对已确认范围内、已关机的原任务恢复既定设置并回读，运行中只提示，不强制关机；不删除共享目录或磁盘 |
| 创建参数页让人误以为随时可改 | 新建参数确实传入后端，但旧任务固定参数仍显示可编辑 | 新建前参数真实生效；载入已有 VM 后明确锁定固定参数；提供单独的关机后调整入口 |
| 自动安装首启/来宾工具指引不足 | Windows ISO 按键、人工安装后账号与 Guest Additions 等步骤未明确衔接 | 在应用内按当前进度提示；不将 windows-started 当作 Windows 已安装或来宾工具已就绪 |

## 验证结果

本轮实现了上表代码路径，并补上以下体验调整：导航与当前指引共用一个左侧栏，虚拟机桌面占据右侧；页面切换时保留来宾运行，恢复连接优先复用同一个任务。控制台进程已启动但窗口未就绪时等待，不再次启动前端；所属弹窗不会被当作主控制台。Windows 就绪后给出 Clash / AdsPower 检查清单，并提供原环境回读入口。

- .NET Release 构建与单文件自包含发布成功，版本 `0.4.0-dev.20261117.unified1`。
- 自动检查共 **250 项通过、0 失败**：C# 127、WPF UI 34、PowerShell 89。范围为合成任务、本机回环服务和独立测试窗口，不包含真实来宾部署。
- 使用 106 条合成 Trojan 节点验证 70 条允许原节点证书选项、36 条保留验证选项；单节点错误不阻断相邻节点。没有把本人订阅、账号或 API Key 放入测试或交付包。
- 实际渲染查看了统一侧栏与软件检查页。独立原生 HWND 的嵌入、尺寸适配、恢复父窗口和弹窗排除检查通过；此测试与真实跨进程虚拟机键鼠测试不同。
- 发布 ZIP 限定 7 个文件，核对 CRC 和 SHA-256；解压后再次运行程序自检及 WPF 预览检查，均通过。客户包不包含开发目录、日志、虚拟磁盘、真实任务或凭据。

## 仍需实机确认

1. 此前真实黑屏尚未证实解决。已观察到全黑画面、NEM 模式与宿主 Hyper-V/VBS 生效；这些现象不足以确认唯一根因。新增只读诊断及关机后 CPU/内存调整入口，3 核兼容对照也仍待验证。本轮没有重启原 VM、改主机安全功能或操作真实任务。
2. Windows 10 2004+ x64 的判断与后端推荐已改，并完成合成测试；真实客户机的虚拟化驱动、跨进程权限、DPI、键鼠、首次弹窗以及完整安装尚待验收。Windows 11 来宾仍有自己的硬件与许可要求。
3. 程序内控制台连接已实现 VirtualBox 与 Hyper-V。VMware 原部署能力保留，多窗口控制台嵌入尚未实现。虚拟化组件、Windows 镜像与虚拟磁盘仍需实际安装/落盘。
4. 真实订阅节点是否连通、Clash/AdsPower 运行参数、断线恢复、重启后回读、公网检测以及本人登录 Claude 都要按各项真实证据验收；源码测试不会把它们标为通过。
