# Claudome 旧盘清理与安装进度（2026-11-17）

当前版本 `0.2.0-dev.20261117.progress1`。按用户要求将旧半成品盘改为成功后自动清理，并补足安装过程提示。本轮仅修改源码、运行隔离离线测试与生成开发 EXE，没有安装/启动真实 VM、挂载实际 VHD、修改主机规则或使用真实凭据。

## 下载和安装恢复

- 下载中的安装文件保留 `.part` 与版本元数据，使用范围请求继续下载；服务器忽略范围请求时安全重新获取，最终须通过哈希核验。已有通过核验的 ISO 和资源复用，不因重试安装而强制重新下载。
- VirtualBox / VMware 已开始的 Windows 安装继续打开原虚拟机并等待安装完成。Hyper-V 已完整写好的系统按安装检查点继续挂盘、引导与启动。
- Hyper-V 离线写入中断时，只重做未完成的系统写入，复用本机 ISO。未承诺 DISM 按 40% 等百分比断点续写；当前官方 Apply-Image 参数未提供这种续写入口。这与下载断点续传不同。

## 旧半成品盘自动清理

1. 重试期间临时记录旧失败盘，以便新盘安装未成功时仍能定位问题。
2. 新 Windows 已启动、来宾工具可用，并通过目标 VM / Workspace 身份确认后，开始清理旧盘。
3. 先完成整个删除计划的检查，再删除本任务 checkpoint 清单内、位于该任务 VM 目录直接子级的旧失败盘文件。只删文件，不递归删除目录。
4. 当前盘、其他 VM 直接引用的盘和 Hyper-V 差分父盘链受保护；VMware 检测快照或保存状态时推迟清理。无法核验引用时保留待办，不强制删除。
5. 每次成功删除后更新清单。锁定、权限或引用问题会显示“旧盘清理待处理”，在继续部署时重试。新系统的后续配置可以继续。

删除动作只对已授权的旧失败盘执行；不会删除原 ISO、下载缓存、正常安装的活动盘、客户其他 VM 或项目备份。测试中的删除对象均为输出目录内的微小文本替身，不是真实虚拟磁盘。

## 安装进度显示

| 过程 | 界面反馈 | 百分比依据 |
|---|---|---|
| 资源下载 | 已下载大小、速度与百分比；复用缓存显示已核验 | 实际字节数 / 响应大小 |
| 镜像核验、建机、恢复 | 当前步骤与活动指示 | 不提供估算百分比 |
| Hyper-V 应用系统映像 | 正在写入 Windows 系统映像 · xx% | DISM 标准输出的实际百分比，使用 /CheckIntegrity 与 /Verify |
| 系统首次启动、来宾工具 | 等待状态、已等待分钟数，提示查看 VM 安装窗口 | 未知整体进度时显示不确定进度条 |
| 验证新系统、清理旧盘 | 清理状态、已删除与待处理数量 | 依据实际清理结果 |
| 软件配置及自动步骤结束 | 当前阶段、待处理指引 | 自动步骤结束不等于浏览器/Claude 业务验收通过 |

进度通过当前操作的受保护管道回传，只接受预定义步骤与 0–100 的有效数值。不会把 DISM 原始输出、命令行或安装输入打印到界面。暂停不会强杀正在写系统的 DISM；UI 管道关闭时仍排空输出并等待进程结束后再卸载本次 VHD，避免孤立写入进程。
