# Claudome · 给 Claude 一个独立的空间

> **Claudome = Claude + Dome（穹顶）**  
> 为 Windows 11 打造硬件级隔离的独立安全工作区，给 Claude 一个安静、独立、边界清晰的空间，与你的日常主机环境彻底分离、互不打扰。  
> **开箱即用**：下载解压双击 `Claudome.exe` 即可运行，无需安装 Go、.NET SDK 或 Codex。

- **最新正式版**：[**Claudome v0.5.0 专线版（Windows 11 x64）**](https://github.com/binlin0120/Claudome/releases/tag/hyperv-v0.5.0)
- **历史兼容版**：[**Claudome v0.4.10（Windows 家庭版 / 旧多线路任务）**](https://github.com/binlin0120/Claudome/releases/tag/v0.4.10)
- **开源许可**：[MIT](LICENSE) · 第三方组件与素材边界见 [NOTICE](NOTICE.md)

## 为什么选择 Claudome？

平时直接在主力电脑上使用 Claude，往往会遇到几个很头疼的问题：本地代理频繁切换导致出口漂移、日常浏览器与账号环境混在一起、断网或关代理时悄悄走回直连、或者折腾半天系统设置与防火墙仍不确定到底有没有泄漏。

**Claudome** 把整套复杂流程收敛成一个可视化桌面程序：
- **不污染主力电脑**：工作区运行在独立的硬件级隔离环境里，宿主机里的个人文档、工作代码、日常浏览器与登录态对工作区完全不可见。
- **不靠嘴说“安全”，而是可验真**：内置一键四维安全验真与重启持久复核，外层网关、来宾防火墙、真实出口、DoH 加密解析与断线阻断全部现场实测回读。
- **日常顺手像本地应用**：16:9 1080p 连续缩放内嵌桌面、无弹窗纯文本直贴剪贴板、断点续装、自动保存进度，下次打开一键回到专属桌面。

```text
┌─────────────────────────────────────────────────────────────────────────┐
│  你的日常 Windows 11 主机                                                │

│  · 凭据与节点配置仅存本机（当前 Windows 用户 DPAPI 加密，不上传云端）      │
└───────────────────────────────┬─────────────────────────────────────────┘

                                ▼

│  外层受控网关与门禁（Claudome 托管）                                      │
│  · 按任务绑定唯一端口与入站规则，关闭助手即断开外层出站，无 NAT/直连兜底    │

                                │ 唯一受控通道 + 纯文本剪贴板通道
                                ▼
┌─────────────────────────────────────────────────────────────────────────┐
│  Claudome 独立安全工作区（Windows 11 隔离环境）                           │
│  · 第二代安全启动 + 虚拟 TPM，独立虚拟磁盘                                │
│  · 来宾默认拒绝出站防火墙 + Clash TUN 接管 + DoH 加密解析                  │

└─────────────────────────────────────────────────────────────────────────┘
```

## 核心功能亮点

### 1. 流畅的专属桌面体验
- **16:9 连续缩放内嵌桌面**：直接在 Claudome 主窗口内流畅操作 1920×1080 工作区，支持全屏、收起顶栏，也可一键切到**独立窗口模式**自由拖动缩放；同时保留原生控制台显式回退入口，切换串行无冲突。
- **无弹窗双向纯文本剪贴板**：在主机和工作区之间直接 `Ctrl+C` / `Ctrl+V` 互传纯文本，同时在底层严格锁定禁用磁盘映射、USB、打印机与音频等设备重定向。
- **外观与空间管理**：支持日间 / 暗夜视图与自定义窗口背景透明度；内置「存储与备份清理」页面，可按类别安全预览并清理暂存目录与历史备份。

### 2. 一键四维安全验真与重启复核
在进入正式使用前，Claudome 会按顺序给出可核查的实测结论，不拿“大概没问题”糊弄：
1. **防护与运行配置**：核对外层网关、总线隔离、来宾 Clash 运行配置与 Windows 默认拒绝出站防火墙策略；发现非本任务组的放行规则立即告警并阻断外层连接。
2. **来宾出口核对**：实测验证工作区实际 HTTPS 出口与任务设定的国家/地区、预期出口一致。
3. **DNS 与旁路检查**：核对加密 DoH 解析有效，同时验证物理上行直连 DNS 被防火墙拒绝。
4. **断线阻断与恢复**：短暂停止来宾代理核心几秒，验证停核期间直连被完全阻断，随后自动恢复连接并复核出口。
5. **重启后持久复核（高级检查）**：支持正常重启工作区并重新登录后，在不自动改写配置的前提下只读复核持久化防火墙与出口状态。

### 3. 断点续装与本机隐私保护
- **随时暂停，下次续接**：镜像下载支持断点续传；创建环境、部署软件或重启主机后重新打开程序即可自动识别阶段继续。
- **资料全留本机**：节点订阅、来宾密码与任务状态全部保存在你自选的本地任务目录，敏感信息使用当前 Windows 用户的 DPAPI 加密，支持一键导出脱敏验收报告与客户使用手册。

## 快速上手（三步完成专属空间）

### 准备条件
- **操作系统**：Windows 11 x64 **专业版 / 企业版 / 教育版**（需在 BIOS/UEFI 开启硬件虚拟化）
- **硬件建议**：8 GB 及以上内存（推荐 16 GB+），任意固定 NTFS 分区建议预留 **95 GB** 可用空间
- **自备资料**：合法的 Windows 11 x64 镜像（ISO）、你自己的网络代理节点/订阅，以及 AdsPower 账号

### 第一步：下载并启动
1. 前往 [**Claudome v0.5.0 发布页**](https://github.com/binlin0120/Claudome/releases/tag/hyperv-v0.5.0) 下载最新版 ZIP 安装包，**完整解压到一个单独的本地目录**。
2. 双击目录中的 `Claudome.exe` 启动。
   > 本项目为开源自建未签名程序，若 Windows SmartScreen 弹出“已保护你的电脑”，点击 **「更多信息」→「仍要运行」**，建议对照发布页的 `SHA256SUMS.txt` 核验 SHA-256。

### 第二步：按向导部署并完成安全验真
1. **安装向导**：查看本机预检（如尚未开启系统虚拟化功能可按指引启用并重启）→ 选择独立任务保存目录 → 选择或获取官方 Windows 11 x64 ISO（支持扫描本机 ISO、粘贴微软官网直链多线程下载、或使用微软媒体创建工具）→ 配置节点/地区时区与来宾账号 → 开始部署。
2. **安全验真**：部署完成后切到「安全验真」，点击 **「开始验真」** 顺序跑完四维自动验真；随后在工作区打开 AdsPower，按内置指引核对专用环境（`No Proxy`、禁用 WebRTC、时区/地理位置/语言设为「基于 IP」），在**同一个浏览器窗口**访问 `https://ip.net.coffee/claude/` 核对出口一致后，回助手点击 **「确认浏览器出口」→「完成设置」**。

### 第三步：日常一键使用
完成设置后，每次打开 `Claudome.exe`，首页「空间概览」会直接显示 **「空间已落成 / 可进入」**，点击 **「进入桌面」** 即可自动恢复受控网络并进入你的专属工作区。

## 旧版用户（如 `v0.4.10`）一键迁移指南

> **注意**：已发布的 `v0.4.10` 旧客户端本身不含迁移按钮，请通过**新版程序**发起迁移。

1. 从 [**v0.5.0 发布页**](https://github.com/binlin0120/Claudome/releases/tag/hyperv-v0.5.0) 下载最新版 ZIP，完整解压到一个**单独目录**；
2. 双击运行解压后的**新版 `Claudome.exe`**，在概览页或顶部「设置」点击 **「从旧版升级到专线版」**（命令行也可运行新版 `Claudome.exe --migrate-legacy`）；
3. 在向导中选择你原来的旧版程序目录（本机已运行过的安装目录，或刚解压从未运行过的副本均可），预检通过并确认后自动执行 **完整备份 + 原子原地升级**（任一步骤异常自动全量回退至原版）：

| 你当前的环境 | 一键迁移的处理方式 |
| --- | --- |
| **Win11 专业/企业/教育版宿主** | 校验专线包 SHA-256 与产品身份后，先完整备份原多线路版，再原地升级到 `v0.5.0`。 |
| **Windows 家庭版 / 不合格宿主** | 在**任何文件替换前**直接停止并说明原因，零改动保留旧版程序与全部原任务；日后升级系统后可随时重新检查。 |
| **已有硬件隔离任务** | 升级后自动校验任务目录、VM UUID、`WorkspaceId` 与宿主机绑定，无缝续用原任务。 |
| **已有 VirtualBox / VMware 任务** | 原虚拟磁盘、快照与任务记录 100% 保留，并可通过备份目录中的独立旧版程序（`legacy-multi-route-backup-*\Claudome.exe`）继续打开；如需改用新专线版，请显式新建独立任务目录。 |

### 后续在线自更新
`v0.5.0` 专线版拥有专属在线更新通道（与旧版公共清单严格隔离），后续版本只需在软件概览页点击 **「检查在线更新」** 或 **「从本地 ZIP 更新」**，即可通过 SHA-256 校验后原地平滑升级，完整保留任务与虚拟磁盘。

## 常见问题（FAQ）

<details>
<summary><strong>1. 关闭 Claudome 后，工作区里的虚拟机还能直连外网吗？</strong></summary>

不能。工作区移除了普通虚拟网卡，所有网络流量必须经由 Claudome 托管的外层受控网关出站；退出 Claudome 后外层网关会立即停止，工作区没有任何 NAT 或直连兜底。下次重新打开 Claudome 并点击「进入桌面」即可恢复受控连接。
</details>

<details>
<summary><strong>2. 为什么 Windows 家庭版不支持 v0.5.0？</strong></summary>

`v0.5.0` 专线版依赖 Windows 11 专业版 / 企业版 / 教育版原生的硬件级虚拟化隔离能力。如果你当前是 Windows 家庭版，可以继续使用已发布的 [v0.4.10](https://github.com/binlin0120/Claudome/releases/tag/v0.4.10)，或在系统「设置 → 系统 → 激活」升级到 Windows 11 专业版后再使用本版。
</details>

<details>
<summary><strong>3. 在工作区的终端里使用 Claude Code 等命令行工具需要注意什么？</strong></summary>

在工作区内通过 PowerShell / cmd 运行 Claude Code 等 CLI 工具时，流量同样受来宾 Clash TUN 与出站防火墙保护，但不会由 AdsPower 浏览器接管；如需指定终端代理环境变量，请在对应终端会话内核对。
</details>

<details>
<summary><strong>4. 换一台新电脑可以把旧任务目录直接拷过去用吗？</strong></summary>

不建议直接复制私有加密目录。本地凭据使用当前 Windows 用户的 DPAPI 加密，换电脑或换系统账号后无法解密；请在新电脑上新建任务并重新填入你自己的配置。
</details>
