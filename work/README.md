# 本次配置脚本目录

Codex 在 Deploying 模式把本项目需要的 `.ps1` 脚本放在这里。每个脚本应以 `param([hashtable]$DeploymentData)` 接收按需提供的字段；不要输出这些字段，不把密钥写进脚本。执行位置由客户资料中 EXECUTION_PLACE 决定，不能把 GuestLocal 错设在实体主机上。先检查已有状态、备份最小范围，再配置和回读。缺权限或工具明确拒绝时报告，不绕过。

这里没有预装的通用网络写入脚本。现有设备、订阅及网络规则必须先核对，再由本次获准的 Codex 生成适配代码。本版仍是 Codex 辅助的教程与脚本包，并非全自动安装器。
