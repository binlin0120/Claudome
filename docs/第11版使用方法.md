# V11：先填资料，本次配置可执行代码，收尾后锁定

本版是在 2026-11-14 最新教程修订包上制作的第 11 版，保留 V10 的网络验收、后续采购清单和 Mac 下载顺序修订。**这是 Codex 辅助的教程与脚本包，不是双击后无需 AI 的全自动安装器。** V11 新增可实际运行的本地资料导入、限定本次配置的执行器和结束配置命令。

Windows 双击入口使用 PowerShell 7（`pwsh`）；请先确认已安装并可从终端运行。入口缺少 `pwsh` 时会提示并退出，不回退到 Windows PowerShell 5.1。

## Windows 用户照这四步做

1. 解压整个包，放在自己选定的本地任务文件夹。研发测试在 D 盘进行；客户没有 D 盘时，先确认其实际保存位置，不替其新建盘符。
2. 双击 `00_准备部署资料.cmd`。它在当前 Windows 用户的桌面准备 `虚拟电脑部署资料.txt`，已有文件不会覆盖。本人在【名称：】后粘贴需要的项目，保存并关掉编辑器。先读下文的密码说明。
3. 双击 `01_开始本次配置.cmd`，本人输入 `START`，开启本次配置。它把资料用 Windows 当前账号的加密机制保存到包内 `runtime-private`，读回校验后清空桌面原文件的已填内容。把整个任务文件夹交给 Codex，并发送《给Codex的操作说明》开头的 V11 任务。
4. Codex 完成实际配置和逐项验收，确认本次脚本均已结束后，本人双击 `02_结束配置并锁定.cmd`。也可以在包根目录运行：

```powershell
pwsh -NoProfile -File .\tools\V11\Deployment.ps1 -Action Lock
```

需要查看状态时双击 `03_查看配置状态.cmd`。`Deploying` 表示本次配置已开启；`Locked` 表示本包不接受新的部署脚本。**锁定成功不等于网络验收通过。**

若 Windows 因下载文件标记而拒绝脚本，先核对下载来源、ZIP 校验和及文件内容，再由本人按系统提示解除该下载文件的阻止。不要长期调低整机执行策略、关闭安全防护，或绕过 Codex 工具明确作出的拒绝。

## 桌面资料怎么填

每行一个 `【名称：】内容`，例如 `【虚拟机账号：】张三`。只在右括号后直接粘贴，不改括号内的名称，不加引号；密码中的等号、井号、美元符号、括号及前后空格原样保留。不要重复同一名称。旧版已填写的英文 key=value 格式仍可导入，不必重新填。

| 文本里的名称 | 填什么 |
| --- | --- |
| 【执行位置：】 | Windows 主机用 Hyper-V 直接调用虚拟机填 `Windows主机`；脚本本来就在 Windows 虚拟机内运行填 `Windows虚拟机`。不能把 GuestLocal 错选在物理主机上。 |
| 【虚拟机名称：】 | 本次目标虚拟机名，例如 `Claude-Workspace`，以虚拟机管理器现场值为准。 |
| 【虚拟机账号：】 / 【虚拟机密码：】 | 虚拟机内 Windows 账户和真实密码。不是开机 PIN，不是物理主机账户。HyperVHost 执行阶段需要；新虚拟机还没创建账户时，先做不依赖账户的准备，账户建好后只补一次。 |
| 【代理订阅链接：】 | 本人购买且本次要使用的完整订阅。按原教程核对服务及实际格式，不能仅凭“IP1”这个名字猜节点。 |
| 【预期出口IPv4：】 | 本人或供应商明确提供的预期固定公网 IPv4；服务器连接地址不一定是最终出口。没有可靠基准就留空，并将精确出口匹配记为未验。 |
| 【节点名称：】 | 多节点时本次选定节点的准确名字；留空不等于允许 AI 自行挑选。 |
| 【AdsPower账号：】 / 【AdsPower密码：】 | 可选。仅在本次确需登录 AdsPower 时填写。 |
| 【Claude账号：】 / 【Claude密码：】 | 可选。仅在本人授权且当前登录方式可用时填写；Google/Apple 登录、验证码和二次验证不能靠此文件自动完成。 |
| 【VPS服务器地址：】 / 【VPS端口：】 / 【VPS账号：】 / 【VPS密码：】 | 仅使用自建 VPS 且本次确需配置时填写；不相关的留空。 |

文件填写后暂时是明文，先避免桌面同步、截图和上传。如果桌面被 OneDrive 等同步，可指定一个本地且不在同步范围的文件：

```powershell
.\tools\V11\Deployment.ps1 -Action Prepare -InputPath 'D:\本地任务资料\部署资料.txt'
.\tools\V11\Deployment.ps1 -Action Begin -InputPath 'D:\本地任务资料\部署资料.txt'
```

上面目录要先由本人选定并存在，示例不是强制路径。导入成功后会清空当前这份文件里的已填内容，**不会清除此前的云端副本、截图、编辑器备份或文件历史**。加密资料绑定导入时的 Windows 用户和电脑，不是可以随意跨机器复制的密码库。同一用户下有权限运行代码的其他程序仍可能解密，因此不是对管理员或恶意程序的隔离。

结束配置会删除本包的临时加密副本，不清除 Clash、AdsPower 等软件正常运行所需的合法设置和已登录状态。以后另开维护任务需要本人重新准备必要资料和授权，不保留永久管理通道。

## Codex 怎么使用，避免反复要密码和隔屏点击

中文标签在本地导入时固定映射为原有内部字段：例如【虚拟机密码：】对应 VM_PASSWORD、【代理订阅链接：】对应 PROXY_SUBSCRIPTION_URL。因此原有脚本的 -Fields 参数保持不变；模型不需要读取原始资料内容。

仓库源码维护与虚构资料离线测试按根目录指令的维护范围执行，不需要开启真实部署会话。

1. 每次开始和恢复先读本包 `AGENTS.md`，Claude Code 同时读 `CLAUDE.md`，检查本次状态与目标机器。只读取状态，不把桌面资料、加密资料或解密结果放进模型上下文。
2. 先识别当前执行位置、已有虚拟机和可用通道。`HyperVHost` 使用正式的 PowerShell Direct 接口，不额外开放网络端口；它仍要求合适的主机和来宾系统、已运行的目标虚拟机、虚拟机账户及相应权限。**预填密码不保证通道一定可用**，失败不得直接认定密码错误。
3. 把一组相关配置写成包内 `work\本次步骤.ps1`，脚本使用 `param([hashtable]$DeploymentData)`。它只通过参数接收明确申请的字段；不写死真实资料，不输出密码，不把资料拼进可执行命令字符串，不使用 `Invoke-Expression` 执行资料。先盘点、最小备份、再改动、回读和验证。
4. 经执行器运行脚本。本例只传订阅，不传其他账号密码；目标虚拟机和 Windows 凭据由本地模块取用，不进入这条命令：

```powershell
.\tools\V11\Deployment.ps1 -Action Run -ScriptPath 'D:\实际任务文件夹\work\本次步骤.ps1' -Fields PROXY_SUBSCRIPTION_URL -TimeoutSeconds 300
```

多个字段可在 PowerShell 里用逗号列出，例如 `-Fields PROXY_SUBSCRIPTION_URL,PROXY_NODE_NAME`。`HyperVHost` 把代码直接交给指定来宾执行；`GuestLocal` 在当前 Windows 进程所在电脑执行，所以必须先确认当前已在目标虚拟机内。代码从受控脚本文件加载，资料通过独立参数传入，两者不可混用。

5. 一次运行默认最多等 300 秒，可为本步骤显式设置 1—1800 秒。超时或失败停止本次作业并报告；**不保证脚本自行启动的所有独立系统进程都已终止**，继续前要核对。正常输出中的已知资料原值会替换为“已隐藏”，但不能代替脚本本身避免输出秘密；编码后或拼接后的敏感内容不保证能自动识别。
6. 需要补充资料时，由本人在本地文件补齐，再运行 `-Action Import`，不让本人将密码发到聊天。已有软件和账号不重复安装、退出或重登。付款、验证码、安全桌面上的管理员授权，以及浏览器工具要求本人处理的登录步骤，仍由本人完成。
7. 如果工具明确拒绝该动作，保留脱敏错误并停在受影响步骤；**本包的部署模式不覆盖工具平台的安全规则，不是换一种入口继续同一个被拒动作的许可**。

本版没有自带适配所有订阅和软件版本的统一网络写入脚本。配置代码由本次获准的 Codex 按现场事实生成，原有专用检查脚本继续复用；不能把本版说成完全自动配置器。新虚拟机的初始安装、首次账户创建和执行通道建立也没有凭空自动化，先按原教程完成必要引导，不能承诺填写文件即可跳过它们。

## “结束配置”到底限制什么

- 执行器每次启动脚本前检查状态；默认、缺状态、损坏状态、用户或机器不匹配均拒绝启动。结束命令先保存 Locked，再删除本包的临时加密资料。
- `AGENTS.md` 和 `CLAUDE.md` 要求本次结束后停止输入、修改及执行部署代码，不从编辑器、终端、GUI 或其他入口绕过。此后只解释既有报告和读取非敏感状态。要新开配置，必须由本人确认并重新开启。
- **不能强制控制所有 Codex 工具、其他聊天、其他目录、管理员或其他软件，也不会修改其全局配置。** 项目规则属于 AI 应遵守的约定，本包执行器的状态检查属于入口限制；二者都不是整机的代码执行禁令。
- 结束命令不杀掉此前已经启动的进程，也不撤销原有系统管理员权限。先确认本次作业已结束，再锁定并退出本次配置聊天。需要操作系统级强制限制时，必须另行设计受限账户和工具权限，不能宣称本版已做到。

## Mac 怎么走

保留原 Mac/Fusion、镜像来源及下载速度核对流程。V11 的 Windows 加密资料与执行器需要在 Windows 中运行，不能把 DPAPI 当成 Mac 加密方式。

Mac 主机可由本人运行 `sh ./tools/V11/session-mac.sh start` 开启本次项目规则，收尾运行 `sh ./tools/V11/session-mac.sh lock`；它**只切换项目规则状态，不是强制执行器，也不保存密码**。脚本静态核对但未在真实 Mac 运行，实际结果须现场验收。不要把 Windows 测试说成 Mac 已通过。

Mac 用户如需 V11 的加密资料助手，应将包放进目标 Windows 虚拟机，在来宾桌面准备资料并将【执行位置：】填为 Windows虚拟机。本人可一次性通过已获准的本地传输方式移入所需资料；不要通过聊天或云盘传密码。该通道如何首次建立、来宾权限是否足够仍须现场确认。Mac 原生钥匙串自动读写和 Fusion 凭据自动调用未实现，不能宣称与 Windows Hyper-V 等同。

## 常见错误

- `DEPLOYMENT_LOCKED`：本次未开启或已结束；交本人重新授权，不自行改状态。
- `LOCAL_CREDENTIALS_MISSING/UNAVAILABLE`：没有资料，或不是导入时的 Windows 账号/电脑；本人补充，不猜密码。
- `VM_CREDENTIALS_REQUIRED_FOR_POWERSHELL_DIRECT`：缺来宾真实账号密码；PIN 不能替代，现有 Windows 许可、账户及权限仍需按系统要求处理。
- `INPUT_FIELD_UNKNOWN/DUPLICATE/FORMAT_INVALID`：前缀拼错、重复或不是“【名称：】内容”，只报告字段问题，不回显敏感行。
- `TASK_FAILED/TASK_TIMEOUT`：本次作业失败或超时；按步骤核对代码、权限与虚拟机执行通道，不自行重复同一个已被工具明确拒绝的动作。
- `SCRIPT_OUTSIDE_TASK_WORKSPACE/SCRIPT_REPARSE_POINT`：脚本不在本包 work 目录或通过目录链接越界；核对真正属于本次任务的脚本，不扩大访问范围。
- `LOCAL_OPERATION_FAILED`：本地文件、访问权限或系统组件不满足；先保留非敏感状态，不能据此声称账号密码错误。
