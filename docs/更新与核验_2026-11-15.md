# 2026-11-15 V11 更新与核验

## 新版增加了什么

V11 输入包共 53 个文件，相对 2026-11-14 Mac 下载流程修订包新增 18 个、修改 12 个，未删除文件。输入 ZIP 的 SHA-256 为 `79dab3d2e5f9de802b512ccfd776eaa90d52268d0b7ca7dce9c190ceeeb6fb79`。

- 新增中文资料模板，使用“【名称：】内容”，兼容旧英文 key=value 格式，保留密码中的特殊字符和前后空格。
- 新增四个 Windows 双击入口：准备资料、开始本次配置、结束配置并锁定、查看状态。
- Windows 本地助手将本次资料按当前用户及电脑加密保存，读回验证后清空输入文件的已填内容；执行脚本时按字段传入资料。
- 新增 Deploying／Locked 阶段与工作目录执行器，包含路径限制、超时处理、已知原值脱敏及结束时删除临时加密副本。
- 新增 Mac 项目阶段脚本、使用说明及 40 项 V11 测试。Mac 脚本只切换项目规则状态，未实现原生密码库或 Fusion 凭据自动调用。

## 开源仓库合并处理

保留 MIT、李诗恩与林琛署名、Claude-Cage 交流与沿革说明、既有交流群，以及 Windows 专业版建议。保留 Mac 下载顺序、按软件补充联网规则、Windows 地区与时区跟随最终出口节点的要求。
