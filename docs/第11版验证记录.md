## 尚未验证

- 真实客户虚拟机的首次安装、账户创建、PowerShell Direct 权限和连续运行。
- 真实订阅导入、准确固定出口、DNS 实际去向、真正停止代理核心、恢复及重启。
- AdsPower、Claude 的真实账号登录、验证码和真实消息发送。
- 真实 Mac/Fusion 的模式脚本与 Windows 来宾流程。Mac 原生钥匙串读写及 Fusion 凭据自动调用没有实现。
- 跨 Windows 用户或机器的实测：本版使用系统 DPAPI 的当前用户加密机制，但没有另建系统账户测试。
- 对全部 Codex 工具或整机强制禁止代码。本版仅强制检查本包执行器入口，并提供项目指令；结束命令不会杀掉已经启动的所有系统进程。

逐项机器可读结果见 `第11版验证结果.json`。测试输入没有真实密码、订阅和服务器资料；运行私有目录及本机完整测试输出不放入分发 ZIP。
